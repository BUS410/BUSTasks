# TaskFlow

Веб-приложение для создания и ведения задач на Flask и SQLite. Регистрация и вход не требуются.

## Возможности

- Создание, просмотр, редактирование и удаление задач.
- Название, описание, планируемая дата, приоритет, статус и исполнитель (строкой).
- Комментарии с необязательным именем автора на странице задачи.
- Список задач с пагинацией по 20 элементов.
- Фильтрация списка по статусу и приоритету, сортировка по дате создания, сроку или названию.
- Изменение статуса прямо в списке задач.
- Удаление задач со страницы задачи или прямо из списка.
- Даты отображаются в формате `ДД.ММ.ГГГГ`, время создания и комментариев — с часами и минутами.
- Завершённые задачи отображаются приглушёнными серыми.
- Данные хранятся локально в SQLite в `instance/tasks.sqlite3`.

## Запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask --app app run --debug
```

Откройте http://127.0.0.1:5000. Таблицы базы данных создаются автоматически при запуске приложения.

Для постоянного ключа Flask-сессии задайте переменную окружения `SECRET_KEY`. Приложение не использует учётные записи; ключ нужен для защиты форм от CSRF.

В конфигурации WSGI на PythonAnywhere можно импортировать `app` из `flask_app.py`; эта точка входа использует то же приложение, что и `app.py`.
